# AsKen-POS-Flutter
AsKen POS is a modular, offline-first Flutter POS system designed for an educational supply store. It combines local Drift persistence, Riverpod state management, resilient Google Drive synchronization, versioned database backup and recovery, owner-controlled operations, and durable transaction-printing workflows. The architecture prioritizes data integrity: transactions are saved before external operations, sync and print failures are recoverable, and sensitive workflows remain available without requiring continuous connectivity.


Drift, Flutter, Google API
(Personal Project for a small family-owned business)
